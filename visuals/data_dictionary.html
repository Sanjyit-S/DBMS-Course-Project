routes

Infrastructure
Master point-to-point flight corridors with geographic displacement.
Column NameData TypeKey / ConstraintReferential ActionBusiness Invariant / Description
PK route_id
 INT SERIAL NOT NULL - Monotonic surrogate sequence identifier for corridor.
FK origin_airport
 CHAR(3) NOT NULL REFERENCES airports(airport_code) ON DELETE RESTRICT Departure terminal code. Airport cannot be deleted while routes exist.
FK dest_airport
 CHAR(3) NOT NULL REFERENCES airports(airport_code) ON DELETE RESTRICT Arrival terminal code.
distance_km
 NUMERIC(7,2) CHECK (> 0) - Flight corridor displacement in km. Strictly positive.
Table Constraint
 - CHECK - CHECK (origin_airport <> dest_airport) prevents circular self-loop flights.

Column NameData TypeKey / ConstraintReferential ActionBusiness Invariant / Description
PK aircraft_id
 INT SERIAL NOT NULL - Physical airframe hardware identifier.
model
 VARCHAR(50) NOT NULL - Equipment model (e.g., 'Airbus A320neo', 'Boeing 737-800').
total_capacity

seats

Infrastructure
Airframe internal seat topology and cabin tier stratification.
Column NameData TypeKey / ConstraintReferential ActionBusiness Invariant / Description
PK seat_id
 INT SERIAL NOT NULL - Surrogate physical seat identifier.
FK aircraft_id
 INT NOT NULL REFERENCES aircraft(aircraft_id) ON DELETE CASCADE Physical airframe ownership. Scrapping airframe cascades seats.
UQ seat_number
 VARCHAR(4) NOT NULL - Row/Column coordinates (e.g., '1A', '2B').
seat_class
 VARCHAR(15) CHECK IN - CHECK (seat_class IN ('ECONOMY', 'BUSINESS', 'FIRST'))
Composite Unique
 - UNIQUE - UNIQUE (aircraft_id, seat_number) guarantees no duplicate seat labels on same airframe.

flights

Operations
Scheduled operational segments dispatched onto specific physical airframes.
Column NameData TypeKey / ConstraintReferential ActionBusiness Invariant / Description
PK flight_id
 INT SERIAL NOT NULL - Operational segment token (e.g., Flight 101).
FK route_id
 INT NOT NULL REFERENCES routes(route_id) Flight corridor deployed. Indexed via idx_flights_search.
FK aircraft_id
 INT NOT NULL REFERENCES aircraft(aircraft_id) Airframe deployed. Subject to seat compatibility trigger.
scheduled_departure
 TIMESTAMP NOT NULL - Off-block scheduled departure time.
scheduled_arrival
 TIMESTAMP NOT NULL - In-block scheduled arrival time.
flight_status
 VARCHAR(15) CHECK IN - State machine: ('SCHEDULED', 'BOARDING', 'DEPARTED', 'ARRIVED', 'CANCELLED', 'DELAYED').
Table Constraint
 - CHECK - CHECK (scheduled_arrival > scheduled_departure) enforces temporal progression.

bookings

Commercial
Commercial transaction orders placed by primary account holders.
Column NameData TypeKey / ConstraintReferential ActionBusiness Invariant / Description
PK booking_id
 INT SERIAL NOT NULL - Surrogate order transaction identifier.

 CHAR(6) NOT NULL - Passenger Name Record (PNR) token (e.g., 'PNR001'). Indexed for instant search.

tickets

Commercial
Individual travel coupons allocating physical seats to passengers on operational flights.
Column NameData TypeKey / ConstraintReferential ActionBusiness Invariant / Description
PK ticket_id
 INT SERIAL NOT NULL - Unique segment ticket coupon identifier.
FK booking_id
 INT NOT NULL REFERENCES bookings(booking_id) ON DELETE CASCADE Parent commercial reservation order.
FK flight_id
 INT NOT NULL REFERENCES flights(flight_id) Scheduled flight leg allocated. Indexed via idx_tickets_flight.
FK seat_id
 INT NOT NULL REFERENCES seats(seat_id) Physical seat hardware unit assigned.
fare_amount
 NUMERIC(10,2) CHECK (>= 0) - Point-in-time fare transacted. Immutable for GAAP financial auditing.
ticket_status
 VARCHAR(15) CHECK IN - Lifecycle state: CHECK (ticket_status IN ('ISSUED', 'CHECKED_IN', 'CANCELLED')).
Composite Unique
 - UNIQUE - Core Invariant 1: UNIQUE (flight_id, seat_id) guarantees exactly one passenger per physical seat.
